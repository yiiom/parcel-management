### D-23：EC2 以 IP 憑證啟用 HTTPS（2026-10-11）

使用者確認繼續設定 HTTPS，目前沒有網域，先以 IP 54.199.27.86 申請憑證。採用 Let's Encrypt 的 IP 位址憑證：只能使用 shortlived 設定檔，效期約 6 天，以 HTTP（80 埠）驗證。技術安排：以 Certbot 官方 Docker 映像（5.8.0，固定 digest）用 webroot 方式申請，憑證與 ACME 帳號存放於主機 `/opt/parcel-management/shared/letsencrypt`，不進映像與版本管理；systemd timer 每 6 小時檢查續期，有更新才重新載入 Nginx。Nginx 設定分為 HTTP 與 HTTPS 兩份，由主機環境檔的 NGINX_CONF 選擇，CI 串接檢查以自簽憑證驗證 HTTPS 設定。憑證路徑使用固定名稱 `parcel`，日後取得網域時只需重新申請，不必修改 Nginx 設定。
